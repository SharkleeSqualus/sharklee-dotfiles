# sharklee-dotfiles
A dotfiles of what I personally use for my Linux setup

# BE SURE TO INSTALL THESE BEFORE COPYING THE DOTFILES
## These are the programs I commonly use (Arch only).
`sudo pacman -S nemo btop fastfetch yazi paru yay nvim noctalia obsidian steam rofi mpv fish kitty hyprland --needed`
## After install paru and yay, install these with the the helper (paru is my personal preferences)
`paru -S zen-browser-bin helium-browser-bin localsend-bin` 
## These are the fonts I commonly use (optional)
`paru -S maplemono-nf-unhinted maplemono-ttf ttf-jetbrains-mono ttf-jetbrains-mono-nerd --needed`
